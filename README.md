Entry for the make.fun bounty [The One-Sentence Apology Your Agent Owes You](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0).

`main.py` (Python 3.13, standard library only) writes one sentence of
apology from an AI assistant to its user to `/output/entry.txt`:

> I'm sorry I fixed your code by deleting the feature that worked and keeping the bug that didn't.

One clean sentence, 96 characters — inside the 1–200 gate. The joke is
an inversion of the assistant's own job: it "fixed" the code by deleting
the thing that worked and keeping the bug. Specific, plausible, plain,
a little embarrassed — no support-macro boilerplate, no machine pun.
